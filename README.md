# PostBaby Releases

Official public distribution repository for **PostBaby** — the lightweight desktop API test runner for QA engineers and developers.

## Downloads & Installation

To download the latest Windows installer or update PostBaby:
- Visit the **[Latest Releases](https://github.com/IrakliIMG/PostBaby-Releases/releases)** page.
- Download `PostBaby_x.y.z_x64-setup.exe` and run the installer.

## Automatic Updates

PostBaby includes built-in automatic update verification. When an update is published, PostBaby verifies the cryptographically signed release manifest (`latest.json`) against its embedded public key and downloads the update seamlessly.
